# 宪法（Nature 2026-09-21 定，永久生效，每小时对照）

1. 联想可以用，但最难的是跳出联想。基于机制构建，不把它做成「一个什么什么东西」。
2. 借用别人的东西时必须先问：那个问题当年是在什么条件下被解决的；这些条件在 Jev 的公理下怎么不一样了；
   由此该发展出什么新的机制。只借解法不问条件的，不许进设计。
3. 一系列这样的机制累积起来，要完成过去做不出来的任务。每个小点的优化最终累积成巨大的优化。
4. 一切从本质出发：从逻辑底层、底层原理、底层代码出发。时刻牢记，时刻检查。

## 操作形式：借用登记表

|---|---|---|---|
| LOTUS 逐行单独调用 | LLM 长上下文降质，且每次调用按题收费 | 状态收费、题免费（P5）；带主张材料 500 token 起带偏（P4） | 一状态多题一次问完；片段小、多分层 |

| 查询规划器（System R、Predicate Migration） | 代价与选择率都难估 | 代价 ≈ 状态数（P5），选择率是唯一未知 | 目标函数改为状态数与层数；层边界重规划；离线目录估选择率 |
| 验证器 / best-of-N（Cobbe、Lightman） | 验证器要训练，按候选逐个打分 | Jev 免训练、校准、一状态多候选相对判断（D1、E10） | 选择题锦标赛；置换取众数；unsure 触发再生成 |

| AlphaGo 策略+价值+树搜索 | 封闭博弈，价值网络要训练，标量回归 | 开放任务，价值是校准档位（P13），策略是生成器 | 同一次调用给先验与价值；宁宽勿深；任务无关的闭环 |

## 附则（Nature 2026-09-21）
任何任务清单都只是检验任务无关性的探针，不是目标任务。不预定义「我们要做什么任务」，不为探针任务优化语言。
语言只关于它自己的逻辑；探针换一批，语言不该变。
| 数据库逻辑算子 / 物理算子分离 | 同一逻辑算子有多种物理实现，按代价模型选 | 物理实现是三种题型，其代价与偏置由实测决定（P5、P9、E9b、E10）；同状态多算子可零边际融合（P5） | 语义操作 test/select/measure 与题型分离；编译器按 K、长度、偏置下沉；判断融合与材料裂变 |
| SQL 三值 WHERE（反面） | 三值在 WHERE/CHECK 被隐式打成两值，三十年的坑 | 出口是校准三值且噪声在线附近（P2） | `partition` 显式三流/四流；`Set ∪ unsure 流` 是类型错（E11）；去向表每槽有固定去向 |
| `yield` 生成式（Python/C#） | 惰性序列，顺序语义 | 同层判断要可交换才能融合并发（P5） | `for … yield` 定义为纯映射，体内禁赋值（E7）；顺序用 `loop` |
| 资源预算 / 资源感知类型 | 编译期估算资源上界 | 成本几乎只取决于调用次数（P5），静态可估 | `budget` 必填；E12 最省计划超预算即拒；`jv plan` 逐语句报 |
| 燃料有界递归（Agda/Coq fuel） | 证明终止的技巧 | 非单调（P2、P4）使 fuel 从证明技巧变成语义必需 | `bound` 必填（E5）；耐心变式；键重复即停 |
| `Result`/`Either`（Rust/Haskell） | 失败是值，不是异常 | 「做」触世界会失败（E9b 30% 超时），失败必须进账本且能重放 | `Mat ⊎ fail`；槽含 fail → `failed` 出口；四流 |

## 登记行增补（2026-09-23，问题理论调研）

依 Nature 2026-09-23 授权，Fable 裁定（`地基/附注/2026-09-23-决策单B栏-Fable技术裁定.md` §二，逐行推翻条件见该节；来源 `研究/05-问题理论综述-v0.md` §二、四、六、八、十）。第四列为由此发展的新机制；标「（反面）」的是借来作为不采用的依据。

| 借的东西 | 当年解决的问题与条件 | 条件在这类判断器下怎么变了 | 由此发展的新机制 |
|---|---|---|---|
| 划分语义（Hamblin 1958；G&S 1984） | 题的语义 = 可能性的互斥穷尽划分；答案是确定命题；一次一题 | 答案是划分块上的校准分布（P2）；同一谓词同时压在成千上万主体上（P5）；加材料可翻块（P4） | 三题型 = 三种划分；读数是分布、出口是块或弃权；一状态多题 = 划分相交；有界迭代 |
| 初等题结构（Belnap & Steel 1976） | 题 = 主体 + 请求 + 前提；范围限于答案类型提前可算的题 | 主体是材料集合而非个体；前提要在问之前由便宜的前提题核；「提前可算」变成「一跳可判」 | 题式 = 题型 + 槽形 + 请求 + 前提 + 校准记录；前提过滤；insufficient 与 unsure 分开 |
| 探问推理与搜索情景（Wiśniewski 1995–2013） | 题由前提唤出、题推出题、搜索情景是预设的树；答案采纳即为真；代价非形式化 | 答案带错误率，路径可能走错；每步有钱和时延（P5）；树可以在运行时由判断生成 | derive = 唤出的实现；下一题必须收窄（探问蕴涵条件）；骨架 = 情景树模板；黄金路径的概率版 = 深度误差界 |
| 询问模型（Hintikka 1976–2007） | 探究是向自然提问的博弈；主 / 操作问题分层；bracketing 处理假答案，判据交给经验 | 判据不能交给经验，必须是校准阈值；操作问题成批并发 | 校准阈值 + 弃权域替代 bracketing；界定规则 = 语言，策略规则 = 规划器 |
| Rényi–Ulam 带错搜索（Rényi 1961；Ulam 1976；Berlekamp；Pelc 2002） | 向会错的答题者问是非题，求最少题数；错误模型是独立噪声或至多 k 次；每题等价 | 错误率由校准给出且随题式变化；成本按状态不按题（P5）；一层一批、层间自适应；系统性偏读不是随机噪声 | 题量放大系数 1/(1−I(β)) 进规划器；批优先（自适应不省题）；随机噪声与系统偏读分开登记在画像 |
| 噪声二十问的贪心最优（Jedynak 等 2012） | 已知无记忆信道下按 u* 切后验最优 | 信道由校准记录估计、可能不对称；一次可挂多题 | 下一题选择 = 在校准后的信道上按 u* 切候选集；多题时按信道容量之和排层 |
| 信息价值与实验设计（Lindley 1956；van Rooij 2003；Chaloner & Verdinelli 1995） | 一次实验或一道题的价值 = 熵差或期望效用增益；答案无错 | 答案有错误率，价值要按可靠性折扣；三出口代价不对称 | 规划器价值函数 = 效用准则 × 可靠性折扣，按状态算密度；「够用即停」按请求的选择规模 |
| 问题即程序（Rothe 等 2017 / 2018） | 问题从语法生成、按期望信息增益打分；人评优于人生成 | 生成器是大模型或枚举器，打分用校准后的信息值；候选题要过验题闸门才有线 | derive = 生成候选池 → 静态诊断 → 信息值打分 → 校准上岗 |
| 主动学习（Settles 2009；QBC 1992） | 选最不确定或分歧最大的样本问神谕；神谕无错 | 神谕是判断器自身的重跑；分歧来自噪声不来自假设空间 | 重跑分歧作「再问一次」判据；期望路径变化作题的价值 |
| 校准与评分（Dawid 1982；Gneiting & Raftery 2007） | 预报者序贯给概率，事后用严格正常规则评分；连贯不保证校准 | 判断器不是连贯主体，校准只能外部经验检验；真值常延迟到达 | 校准记录按 Dawid 协议分组检验、按对数或 Brier 评分；「待真值」状态 |
| 不精确概率与证据理论（Walley 1991；Dempster 1967；Shafer 1976；Nilsson 1986） | 证据不足以定单点概率时用区间；合并要求证据独立；逻辑相关句子的概率用 LP 给区间 | 多题共享材料，证据不独立；跨题算术被 J-01 禁止 | 计数聚合出区间；逻辑相关题的合成只许区间形式（Fréchet / Nilsson 界）作为 J-01 的唯一例外候选 |
| 多跳误差累积界（Wan 等 2026，近作） | 无弃权的链式成功率 (1−ε)^(K+1)；容量溢出的准确率悬崖 | 每跳可弃权；单跳信息需求由字面化控制 | 带弃权的链式风险-覆盖界（待写）；字面化定律 = 容量对齐 |
| 问答逻辑与前提（Collingwood 1940；Belnap & Steel 1976；Hintikka 1985） | 问题成立要求前提被做出或已建立；先立前提后发问；否定前提是纠正性回答 | 前提本身要由便宜的判断在材料上核，且核的结果带错误率；成批题共享前提 | 前提题先行且共享；insufficient 与 unsure 分开；诊断层的第一条检查是「前提在材料里被做出了吗」 |
| 认知困境二分（Bromberger 1992） | 卡住分两种：候选全被否决 / 无候选；前者可取前提反面为假说 | 否决来自判断器的 ignore 出口，可能是误判；候选可由生成器补 | unsure 的原因枚举加两类：`rejected_all`（换材料或换前提）与 `no_candidate`（调生成器）；前提反面进入 derive 的候选 |
| 对照类与语用解释（van Fraassen 1980） | 为什么题带对照类与相关性关系；相对 K 三分；K(Q) 选取未解 | 参照槽即对照类，可由程序构造；K 的三分直接对应三出口；材料选择用前提题实测 | 参照槽必填于比较 / 打分类题式；材料选择骨架作为 K(Q) 问题的可实测答案 |
| 启发式子问题生成（Polya 1945） | 人解题时的自问清单；无形式语义 | 清单可作为生成器的提示与骨架模板；每条子问题要过验题闸门 | 守则内嵌的子问题生成规则集；分治骨架 = 「只解一部分」 |
| 探究规范（Friedman 2020；Hintikka 1985） | 只追与当前问题相关的证据；效用只对整条策略有定义；无停止判据 | 预算与时延是硬约束；策略要在线评价 | 三条终止线（步数、无进展、预算）作为语言语义；规划器按整层评价而非单题 |
| 查询代数与包含判定（Codd 1970；Chandra & Merlin 1977；AHV 1995） | 查询等价与包含在合取片段可判定；数据精确匹配；求值零代价 | 题的匹配是语义判断带错误率；等价的用途是共用校准与缓存 | 题式等价的结构判据（同题型、同槽形、题面同态）作为校准键合并与缓存命中的候选规则；给题式组合加否定 / 递归前先核分析代价 |
| 知识编译（Darwiche & Marquis 2002） | 离线编译命题理论，在线多项式查询；编译对象无噪声 | 编译产物是带错误率的读数账本；在线目的未知 | 索引 = 一批通用题在料库上的账本；选题方法 = 先列在线操作再倒推题集；每个目的仍需轻量再校准（ScaleDoc 印证） |
| 神谕引导综合与 CEGIS（Jha 等 2010；Solar-Lezama 2006） | 便宜神谕多问、贵神谕问一次；反例排除一批候选；神谕为真值 | 两级神谕都有错误率；反例由「做」产出为字面 | 分层调用协议：便宜判断器收敛后贵判断器复核一次，两级各带校准记录；「做」的输出作为区分性反例进入候选淘汰 |
| （反面）交互证明的重复放大（GMR 1985；PCP，经 Arora & Barak） | 独立重复 c 次错误率 2^−c | 错误系统性相关，独立性不成立 | 重问降错只在重跑分歧检验通过的键上启用；默认按 00 §7 不用〔B9：重问降错只在重跑分歧检验证明错误独立的键上启用〕 |
| 异步验证缓存与级联代理（Krites 2026；ScaleDoc 2026，近作） | 灰区匹配异步验证后晋升；离线表示 + 在线代理 + 级联转交 | 与本项目账本、未决路由、索引构想同构；差别是它们把神谕当真值 | 作为阶段 5 探针候选：用 J++ 复现这两个系统的核心能力 |
| 查询学习（Angluin 1987 / 1988；Angluin & Laird 1988） | 六种查询、反例、噪声下的样本放大；神谕精确或独立随机错 | 判断器错误持久且结构化（pMAT、KDD 2025）；只有成员式判断 | 系统偏读按对抗界估计；等价 / 子集式提问经「做」实现（跑一次给反例）；校准键考虑题式 × 候选类 |
| 查询复杂度（Buhrman & de Wolf 2002） | 神谕不错，只计次数；证书与块敏感度 | 材料槽有成本，判断有噪声 | 最小材料槽 = 证书；题的稳健性 = 块敏感度；代理指标可互换 |
| 决策树学习（Quinlan 1986） | 信息增益；卡方替代阈值；无未决出口 | 有未决出口；线来自校准 | 信息增益作无噪声基准用例；未决出口为新增（第二证据） |
| LLM 作噪声神谕（2024–2025 近作） | 持久错误、验证性提问、回溯修正、允许 unsure | 与本项目前提相同 | 细化 = 验证性提问；账本回溯修正；不靠多数表决 |
| 函数式组合子（parser combinators，Hutton & Meijer 1998；monadic bind，Wadler 1992）〔B98〕 | 组合单元是纯函数，组合零成本、由类型驱动，失败即回溯 | 每个组合点带效应、费用与未决责任；回溯要付钱且读数不可重算 | 组合子只在契约值上定义（B17）：三原语 `gate`/`pick`/`threshold`（`12` §5）加骨架 `sieve`/`pair`/`iterate`；`bind` 的位置由未决续接承担（L-061，`13` §3 责任随包）；不引入以 product/then/bind 命名的独立组合子。推翻条件：两个以上探针项目出现无法由三原语加骨架表达、必须显式 `bind` 的组合 |
| 部分求值与常量传播（Jones、Gomard、Sestoft 1993；Wegman & Zadeck 1991）〔B98〕 | 程序静态已知的部分可在编译期归约，归约保持语义且零成本 | 可归约的只有宿主纯计算与字面量；判断站点是效应不可归约；推测只在同状态零边际时算归约（B51-C1） | 常量传播限于 J-06 `bound`（B69，顶层单赋值整数常量）与 `budget` 估计（B42 可靠下界），不做一般部分求值。推翻条件：两个以上探针项目需要一般部分求值才能给出静态终止或预算证明 |
| Lisp 宏展开 / 分阶段程序（McCarthy 1960；Taha & Sheard 1997）〔B98〕 | 纯语法、零成本、可重复展开 | 三条件在判断器下全不成立：展开若经 `gen` 是效应、要付费、不可重复 | 展开是效应须记账并过检查器（K-233）；「程序作为值」本版不补（K-116、K-106、L-058 随之不做）。推翻条件：两个以上探针项目需要程序作为值（生成并运行 `.jpp` 片段）且 `gen` + 执行器无法表达 |

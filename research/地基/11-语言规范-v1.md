## 0. 范围与设计原则

Jv 是一门**判断语言**：程序由守卫命令 `g → S` 组成，g 是 Jev 的一道校准三值判断，S 是绑定的确定函数。
唯一的非确定运算是判断；其余全是确定性代码。程序可逐字节重放。[08 §2；推导 ← P3]

原则（每条引账本）：
1. **字面化定律**：每道判断必须对面前的材料一跳可判；不字面的先由 S 变字面。边界型错误也要变字面（生成测试→执行→渲染失败）。[推导 ← P1、P10、P16、P19]
2. **三种数字化**：判出位、选出索引、量出档；程序只能被这三种驱动，故三种题完备且最少。[06 §6；推导]
3. **语义操作与题型分离**：源码写 test / select / measure，题型（noul / choice / score）由编译器按校准库里的实测表下沉。[推导 ← E9b、E10]
4. **融合与裂变**：同渲染状态同层的题合成一次请求 [P5]；超窗状态按窗切开 [P4]。
5. **读数不可表达，出口是值**：语法里没有概率；判断表达式的值是出口（act/ignore/unsure、选中项、档位）；线只来自校准。[推导 ← P1、D2]
6. **unsure 是一等出口，程序边界不得静默丢它**：返回类型不含 `⊎ unsure` 时，所有 unsure 必须在程序内被处理。[推导 ← P2；研究 §5.2]
7. **选带先验**：默认候选不被替换，除非替换者的读数超过从标注扫出的边际线；否则保留默认。[推导 ← P19、P20]
8. **成本以预算进、以计划出**：`budget` 必填，`jv plan` 逐语句报层与钱。[J2 §5]
9. **一状态一对象**：对象槽单独占位；多对象同状态待 E16。[P4、A7]
10. **任务无关**：语言只关于自己的逻辑；任务清单只是探针。[宪法附则]
11. **有界迭代，账本只增**：无不动点。[推导 ← P2、P4]

## 1. 词法

- 编码 UTF-8；标识符：Unicode 字母或下划线开头，可含数字；中文可作标识符。
- 关键字（22 个）：`program budget q s pure do anchors import let if else host unsure select as prior switch case while bound improving patience decreasing increasing choose loop escalate drop return for in yield partition where state on ctx over ref`
  （去向词 `escalate refine drop regen anchor keep` 中除 `escalate/drop` 外是普通标识符，红队 05 C2。）
- 题式词：`attr rel cmp class mention degree decide`（七种，设计/F）。
- 字面量：字符串 `"…"`、整数、金额 `$0.10`、时长 `30s`、集合 `{a, b}`、档位序列 `低 < 中 < 高`、出口字面量 `unsure`（只许出现在值位，不许出现在守卫位）。
- 运算符：`∪`（集合/映射并）、`∧ ∨ ¬`（复合守卫）、`< > <= >= ==`（**只在 `host` 表达式里合法**）。
- **没有概率字面量；守卫位没有数值与比较。**
- 注释 `# …`。

## 2. 语法（EBNF，完整）

```
program   ::= "program" ID "(" params? ")" "->" rtype "{" budget decl* stmt* "}"
params    ::= ID ":" type ("," ID ":" type)*
type      ::= "Mat" | "Set" | "Map" | "Q" | "Scale" | "Int" | "Str"
rtype     ::= type ("⊎" "unsure")? ("⊎" "fail")?
budget    ::= "budget" bitem ("," bitem)*                                  # 必填；escalate 缺省 0
bitem     ::= "calls" "<=" INT | "cost" "<=" MONEY | "layers" "<=" INT | "escalate" "<=" INT | "time" "<=" DUR

decl      ::= qdecl | sdecl | adecl | "import" STRING
qdecl     ::= "q" ID ":" form "=" STRING ("probes" STRING)?
form      ::= "attr" | "rel" | "cmp" | "decide" | "mention"
            | "class" "[" ID ("," ID)* "]"
            | "degree" "[" ID ("<" ID)+ "]" "anchors" ID
adecl     ::= "anchors" ID "=" "{" ID ":" STRING ("," ID ":" STRING)* "}"
sdecl     ::= "s" ("pure" | "do") ID "(" params? ")" "->" type "=" STRING

stmt      ::= "let" binder "=" expr
            | ID "=" expr                                    # 赋值：只在 loop/while 体内（含嵌套块）合法（E8）
            | "if" guard block ("else" block)? unsure
            | "if" "host" hexpr block ("else" block)?        # 宿主布尔分支：无 unsure 支
            | "select" guard ("prior" expr)? "as" ID block unsure
            | "switch" guard "{" ("case" ID block)+ "}" unsure
            | "while" "host" hexpr ("decreasing" | "increasing") "bound" INT block
            | "while" guard "improving" ("patience" INT)? "bound" INT block unsure
            | "choose" "{" (guard STRING "->" block ";")+ "}" ("else" block)? unsure
            | "loop" "bound" INT block
            | "escalate" expr | "drop" expr | "return" expr | expr
binder    ::= ID | "(" ID ("," ID)* ")"                       # 元组绑定：接 partition 的三流或四流
block     ::= "{" stmt* "}"
unsure    ::= "unsure" "->" dest ("then" dest)? | "unsure" block
dest      ::= "escalate" | "refine" | "drop" | "regen" | "anchor" | "keep"

guard     ::= call | guard "∧" guard | guard "∨" guard | "¬" guard | "(" guard ")"
call      ::= callee "(" slotarg ("," slotarg)* ")"           # 题的调用：具名槽
callee    ::= ID | "(" expr ")"                               # 一等 Q 值可被调用
slotarg   ::= ("on" | "ctx" | "over" | "ref") ":" expr

expr      ::= literal | ID | call | fcall | "do" fcall
            | expr "∪" expr | "(" expr ")"
            | "for" ID "in" expr "yield" expr                # 纯映射；yield 元组 (k, v) 得 Map
            | "for" ID "in" expr "yield" "(" expr "," expr ")"
            | "partition" ID "in" expr "where" guard         # 三流或四流（含 do 时四流）
            | "state" "(" slotarg ("," slotarg)* ")"
            | "{" (expr ("," expr)*)? "}"
fcall     ::= ID "(" args? ")"                                # S 库函数、组合子、聚合子：位置参数
args      ::= expr ("," expr)*
hexpr     ::= expr (("<" | ">" | "<=" | ">=" | "==") expr)?  # 只在 host 位
literal   ::= STRING | INT | MONEY | DUR | "unsure"
```

约定：
- 题的调用用具名槽：`on` 对象（`attr/rel/degree/mention` 必填；`cmp/decide/class` 可只给 `over`）、`ctx` 语境、`over` 候选集、`ref` 参照。状态由编译器按四槽构造，程序员不拼字符串；`state(...)` 只在把状态当值传递时写。
- `partition x in S where g`：`x` 绑定 `S` 的每个元素，`g` 里用 `x`。守卫不含 `do` → 三流 `(act, ignore, unsure)`；含 `do` → 四流 `(act, ignore, unsure, failed)`。绑定数与流数不符是 E15。
- 字段访问没有点运算；材料的部分一律经 S 函数取（`signature(f)`、`parent(m)`）。
- 字符串字面量在材料位自动成为 `Mat`（地址 `literal:<hash>`，来源 `literal`）；`lit(s)` 是它的显式形式。
- `∪`：`Set ∪ Set`、`Map ∪ Map`（键相同时右侧覆盖）。`Set ∪ unsure 流` 是 E11；要合并必须经 `mark_unsure`。

## 3. 类型

### 3.1 值类型
- `Mat`：唯一材料类型。带地址、来源链（about、made_by）、渲染函数。[选择 | 消融：多类型则来源链与账本键分裂]
- `Set` = `Set[Mat]`。集合里可以含 `fail` 值（来自 `do`）；把含 `fail` 的元素放进题的槽位是运行期 `failed` 出口（§4.8）。
- `Map` = `Map[Mat, Outlet]`，`Outlet = Outlet3 ⊎ 标签 ⊎ 档 ⊎ unsure`。Map 的值位显式携带 unsure，所以 `Map` 永远是 unsure 透明的，返回 `Map` 不需要 `⊎ unsure`。
- `Q`：题，一等值。可赋值、入集合、作候选集、被调用（`(e)(on: …)`）。携带题面、题式、语义操作、验题路径、校准 id。
- `Scale`：刻度，一等值。携带档位序列与锚指纹。
- `Str`、`Int`：宿主值，只在 S 函数参数与 `host` 表达式里出现。
- `T ⊎ fail`：任何类型 `T` 都可以带 `fail` 分量；`do` 的返回类型是 `Mat ⊎ fail` 或 `Set ⊎ fail`；`fail(原因)` 入账本。传播规则统一见 §4.11。

### 3.2 读数与出口
- 读数 `R_test[q]`、`R_select[q, C]`、`R_measure[q, L, anchors]` **不出现在语法里**。唯一能看见读数的地方是 `jv replay`。
- **判断表达式有值，值是出口**：`test` → `Outlet3 = {act, ignore, unsure}`；`select` → `Chosen[q, C] = C ⊎ {unsure}`；`measure` → `Level[q, L] = L ⊎ {unsure}`；`class` → 标签 ⊎ unsure。出口都是 `Mat` 的子类型，可 `yield`、可入 `Map`、可入账本。[红队 05 A1]
- 出口在守卫位被控制结构消费；在值位被 `yield`/`Map` 收集；两者都合法。裸出口不能直接 `∪` 进 `Set`。

### 3.3 编译期错误
| 代码 | 规则 |
|---|---|
| E1 | 读数没有值；守卫位只接受 `call` 或复合守卫；守卫位出现数值、比较、概率、`unsure` 字面量 |
| E2 | 跨候选集比较 `Chosen`；跨刻度或异锚比较 `Level` |
| E3 | 出口的 unsure 未处理：守卫缺去向；或返回类型不含 `⊎ unsure` 而程序内有可达的 unsure 未被 `escalate/drop/mark_unsure/Map` 接住。**明文**：`partition`、`gate`、`threshold` 或任何产生 unsure 流的表达式，其 unsure 流未被消费（未 `escalate`、未 `drop`、未 `mark_unsure`、未进返回值的 `⊎ unsure` 分量、未进 `Map` 值位）即视为静默丢弃，是 E3；绑定了却从未使用的 unsure 流变量同样是 E3。「没写」不等于「处理了」 |
| E4 | `degree` 缺 `anchors`；`anchors` 声明的档与刻度不符 |
| E5 | `while`/`loop` 缺 `bound` |
| E6 | 状态渲染超窗口（材料编译期已知时）；`switch` 未恰好覆盖 `class` 标签 |
| E7 | `for … yield` 体内赋值或含 `loop`；`do` 无法按数据依赖定序 |
| E8 | 赋值出现在 `loop`/`while` 体外（含嵌套块） |
| E9 | `degree` 的状态含同伴（`ctx`/`over` 含同种类候选）却被排序 |
| E10 | `budget` 缺失；`escalate` 出现而 `budget escalate` 为 0 |
| E11 | `Set ∪ unsure 流`（静默并入）；`Set` 与 `Map` 相并 |
| E12 | 静态可估的最省计划超出 `budget`（报最省计划与三条放宽建议） |
| E13 | `improving` 变式的题式不是 `degree` |
| E14 | `select`/`switch`/`choose` 的候选集静态为空 |
| E15 | 元组绑定数与 `partition` 流数不符；`do` 出现在守卫里却只绑三流 |

跨材料的合法运算只有一处：同题同刻度同锚、且状态不含同伴的 `Level` 可做**偏序**排序（相邻档视为并列）与按档计数聚合。期望只在调试器显示。[推导 ← P2、P13、E10]

## 4. 语义

### 4.1 判
`o = outlet_q( jev( render(state), phys(q) ), calib(q, phys, kinds) )`。
- `render` 按 §4.9 格式渲染，格式版本号进账本键。
- `phys(q)` 由编译器下沉（§5.1）；`calib` 的键 =（题面，对象槽种类，语境槽种类，物理题型，渲染版本）。
- 账本键 =（渲染状态哈希，题 id，物理题型，置换种子，渲染版本）。**按题不按题组**，融合不改变键。[P3；J2 §3]
- 槽里出现 `fail` 值 → 该次判断不发请求，出口为 `failed`，按 unsure 去向处理并记原因。[红队 05 B3]

### 4.2 三种控制流
- `if g B₁ [else B₂] unsure U`：act → B₁；ignore → B₂；unsure/failed → U。
- `if host e B₁ [else B₂]`：宿主布尔，无 unsure 支；`e` 里若含 `fail` 值，整个语句出口 `failed`，程序返回类型须含 `⊎ fail`。
- `select g [prior d] as x B unsure U`：
  1. 下沉为 choice 时：对 `over` 做记账置换 2 次；两次 argmax 不一致自动补第 3 次；仍不一致 → unsure。[红队 05 B9]
  2. 下沉为 K 道 noul 时：一层并发，取读数最高者。
  3. **先验规则**：写了 `prior d` 时，只有当选中者的读数高出 `d` 的读数 ≥ 校准库按 K 扫出的边际线时才替换，否则 `x = d` 并记「保留先验」；未写 `prior` 时无此步。[P19、P20]
  4. 线过 → `x = 选中者`，执行 B；否则 U。
  `switch` 是 `class` 静态标签集的 `select`，分支表恰好覆盖（E6）。
- `while host e decreasing|increasing bound n B`：宿主计量，严格单调；不单调即停，出口 `bound`。**宿主变式优先。**
- `while g improving [patience p=2] bound n B unsure U`：`g` 必须是 `degree`（E13）。进步 = 档位比迄今最高档上升 ≥ 1 档（相邻并列不算）。连续 `p` 轮无进步即停，出口 `plateau`；（渲染状态，题）键在本循环内重复 → 立即停，出口 `nochange`；`bound n` 到 → 停。unsure 走 U。[红队 05 A4]

### 4.3 多守卫同真
`choose { g₁ "描述₁" -> B₁ ; g₂ "描述₂" -> B₂ ; … } [else B_e] unsure U`：
同状态融合问全部守卫；恰一条 act → 走它；多条 act → 由一道 `decide` 题（候选 = 各 act 分支的描述字面）决定走哪条；全 ignore → B_e；无 act 且含 unsure → U。描述是程序员写的字面材料。[08 §2；红队 05 B1]

### 4.4 复合守卫
`g₁ ∧ g₂`：融合问全部子题，按强 Kleene 合成（有 ignore 即 ignore；无 ignore 有 unsure 则 unsure）；`∨` 对偶；`¬` 只对出口对调并标注，不是反问。
嵌套 `if` 是短路语义，**不**宣称与复合等价。[J3 §5]

### 4.5 集合、映射与顺序
- `for x in S yield e`：纯映射，体内不得赋值（E7）；元素间独立，同层判断由调度器融合并发。`e` 可含 `do`（按数据依赖定序，结果含 `fail` 时该元素为 `fail`）。
- `for x in S yield (k, v)`：得 `Map`。嵌套 `for` 的 Map 自动扁平；要配对材料用 S 函数 `pairs(A, B)`。
- `partition x in S where g`：三流 `(act, ignore, unsure)`；`g` 含 `do` 时四流 `(act, ignore, unsure, failed)`。`S` 本身是 `fail` 时各流为空、`failed = {S}`。绑定出来的 unsure 流（与 failed 流）必须被消费，否则 E3（§3.3）；确实要丢就显式 `drop 疑`，丢弃入账。
- `loop bound n`：顺序循环，可赋值。
- `do` 按数据依赖定序，无依赖可并发；键 =（程序点，参数哈希，迭代索引）。
- 出口字面量 `unsure` 只在值位（如 `yield (d, unsure)`）合法。

### 4.6 unsure 的去向表（`dest` 对照）
| 目标槽 | 第一去向（`dest`） | 第二去向 | 计数作用域 |
|---|---|---|---|
| 材料 | `refine`：先问 `enough` 模板（材料够回答吗）；不够且可拆 → 细拆再判；够 → 转第二去向 | `escalate` | 按（题，对象来源链根）计，上限 2；细拆的子判断继承父计数 |
| 语境 | `refine`：换一条语境（下一条定义/约定） | `escalate` | 同上 |
| 参照 | `anchor`：加一条锚（参照库有） | `escalate` | 每题 1 次 |
| 问题 | `escalate` | — | — |
| 候选集 | `regen`：`over` 由 `do gen` 产生时再生成一批 | `escalate` | 每 select 1 次 |
| 刻度 | `anchor` | `escalate` | 每题 1 次 |
| 动作 | `keep`：不执行，记账（`select … prior d` 时保留 d） | `escalate` | — |
| 循环 | 退出并记账 | — | — |
| 程序边界 | `drop`：丢弃并记账 | 进返回值的 `⊎ unsure` 分量（须经 `mark_unsure`） | — |

裸的 `if/select/while/choose` 必须显式写去向（`unsure -> refine then escalate`）；组合子（§6.4）在体内实现一次上表的去向，调用时不写。
每次按表走的去向写进账本与轨迹。`refine` 细拆到单段仍 unsure → 不得聚合成确定值，必升级或 drop。
升级请求按对象去重后计入 `budget escalate`；超预算的 unsure 只能进返回值的 unsure 分量或 `drop`，不能进 `Set`。[红队 05 A3、B2]

### 4.7 聚合子（完整签名）
| 签名 | 语义 | 示例 |
|---|---|---|
| `exists(S: Set[Outlet3]) -> Outlet3` | max（有 act 即 act；无 act 有 unsure 即 unsure） | `exists(for p in 对 yield 相反(on: p))` |
| `all(S: Set[Outlet3]) -> Outlet3` | min | `all(for r in 规则 yield 符合(on: 段, ctx: r))` |
| `count(S: Set[Outlet3]) -> (Int, Int)` | 区间 `[n_act, n_act + n_unsure]` | `let (lo, hi) = count(出口集)` |
| `mode(S: Set[Chosen]) -> Chosen` | 众数；平票 → unsure | `mode(投票)` |
| `hist(S: Set[Chosen]) -> Map[标签, Int]` | 直方图 | `hist(类别结果)` |
| `dist(M: Map[Mat, Level]) -> Map[档, Int]` | 档位分布（unsure 单列） | `dist(分)` |
| `median(M: Map[Mat, Level]) -> Level` | 中位档；unsure 超过一半 → unsure | `median(分)` |
| `rank(M: Map[Mat, Level]) -> Map` | 偏序排序（相邻档并列；要求同题同锚且状态无同伴，否则 E9） | `rank(分)` |
| `top(k: Int, M: Map[Mat, Level]) -> Set` | 前 k；边界并列全部纳入并记 W-tie；前 k 内含 unsure 的项单独标出 | `top(3, 分)` |
| `mark_unsure(S: Set) -> Set ⊎ unsure` | 把 unsure 流标成返回值的 unsure 分量 | `return 未见 ∪ mark_unsure(疑)` |
混合聚合由宿主 S 写，须显式处理 unsure 流。

### 4.8 S 与「做」
- `s pure`：无副作用，账本按输入哈希缓存；输入含 `fail` 则返回 `fail`。
- `s do`：触世界，返回 `Mat ⊎ fail`；重放取账本不重触世界。
- 生成器、执行器、渲染器、人（`ask`）都是 S；语言不为它们加原语。[08 §4]
- `⊤ → S`：不带守卫的纯段合法（表达式语句）。
- **渲染是 S 返回类型的一部分**：每个 `Mat` 自带渲染函数（§3.1），`s do` 返回的 `Mat` 的渲染由该 S 的实现给定（`act`/`sense` 返回的屏幕材料，渲染就是可访问性树；`run` 返回的结果材料，渲染就是退出码与输出）。所以 `do act(a)` 的返回值**已经是渲染后的材料**，不需要再套 `a11y`；`a11y(do act(a))` 与 `do act(a)` 等价，套一层是冗余，检查器报 W-rerender，不是错误。`a11y`/`ocr` 只在材料来自非 S 来源（文件里的截图、扫描件）时才需要显式调用。

### 4.9 渲染格式（版本化）
```
[JVR 2]
[对象] …                      # 恰一个对象；对象槽单独占位
[语境 n=2] 1) … 2) …          # 编号，按来源链排序
[候选 k=4] A) … B) … C) … D)   # 仅 select 下沉为 choice；顺序按置换种子
[参照] 低: … 中: … 高: …       # 仅 measure；每档一条锚
```
`subset` 模板（§6.2）渲染为 K 个各带一个 `[对象]` 的状态。格式版本号进账本键与校准键。[红队 05 B8]

### 4.10 升级（escalate）
带预算（`budget escalate <= n`，缺省 0）与去重（同键只问一次）；超预算的 unsure 转为返回值的 unsure 分量或 `drop`；人答回流后同题同材料的其它 unsure 自动复用；人答进校准集。`escalate e` 语句结束程序，返回 unsure 分量 = e。

### 4.11 `fail` 的传播（统一规则，v1.1）
`fail` 是「世界没给出材料」，unsure 是「材料给了但判不出」；两者分开记账，但去向共用 unsure 去向表。一条规则管所有位置：
1. **表达式短路**：任何表达式的任一子表达式为 `fail`，整体为 `fail`（`s pure` 输入含 fail 返回 fail 是它的特例）。
2. **集合逐元素**：`for x in S yield e` 产出 `Set[T ⊎ fail]` 或 `Map`，某个元素的 `e` 为 fail 只让**该元素**为 fail，不让整个集合 fail；`Set ⊎ fail` 只在 `S` 本身是 fail 时出现。
3. **判与聚合**：题的槽位含 fail 元素 → 该次判断不发请求，出口 `failed`（§4.1）；聚合子（§4.7）对 fail 元素按 unsure 流处理（`exists` 里 fail 不算 act 也不算 ignore；`count` 计入 `n_unsure`；`top`/`rank` 单独标出）。
4. **循环**：`while`/`loop` 体内任一语句出口为 fail 或 failed → 本轮出口 `failed`，退出循环，记账；不重试（重试要写在 `do` 的实现里，或由 `loop` 显式再调）。
5. **程序边界**：返回类型不含 `⊎ fail` 时，程序内每个可达的 fail 必须被 `escalate`、`drop`、或 `on_fail(e, alt)` 处理，否则 **E16**。`on_fail(e: T ⊎ fail, alt: T) -> T` 是内建纯函数：`e` 为 fail 时返回 `alt` 并记账。
一行示例：`let 报告 = on_fail(do run("pytest -q", repo), lit("测试未能运行"))` → `报告 : Mat`，后续判断照常；不写 `on_fail` 而返回类型是 `Mat ⊎ unsure` → E16。

### 5.2 融合
同渲染文本逐字节相同、同层的全部题 → 一次请求。多条规则要进同一状态只能进题面（每条一道题），不进语境槽。[红队 04 A1-3]

### 5.3 裂变与合回
超窗（noul 500 带主张、choice 段落级 1.8k、代码级 1.5k，均为**下界**）时按窗切开，对象单独占位；合回按语义操作：
test → `exists`（或按声明 `all`）；select → 分块选后再一层 noul-argmax（不用锦标赛，避免首位偏置相乘）；measure → 按出口计数。`jv plan` 标「待测上限」。

### 5.4 规划器
目标：在「每状态 ≤ 窗口」与 `budget` 约束下，按（层数，钱）字典序最小。层间顺序按 rank = (σ − 1) / 代价；加一元筛值得当且仅当 N_s > K / (w(1 − σ²))。
层边界重规划（实测幸存率偏离预估 > 2 倍）。并发按状态大小自适应。
静态可估的笛卡尔积报 W-cost 并要求显式 `allow pairs`。**最省计划超预算 → E12**（报最省计划与三条放宽建议：放宽 K、加一元筛、减 bound）；动态部分运行时到预算即停，剩余对象标 `bound`。[红队 05 B4]

### 5.5 干跑报告
`jv plan` 输出与源码逐语句对齐的旁注：`层 n · 调用 k · 下沉 choice/K-noul · 裂变 m 块 · 预估 token · $ · s`，并与 `budget` 比对；超阈值（默认 $0.10）要 `--confirm`。`time` 预算按 层数 × p95 + 排队 估算，与 `layers` 二者填一即可。

### 6.2 题式（七）与模板（二）
题式按判据分：`attr`（属性）、`rel`（关系）、`cmp`（比较）、`class`（归类，静态标签）、`mention`（提及：「x 的文字里出现了 h 描述的东西吗」，溯因由宿主组合）、`degree`（程度）、`decide`（决定，判据前瞻，含「下一问」）。[设计/F 188/188]
模板（写法上是题式的用法，不是新题式）：`subset` = `attr` 在集合上的向量化（`for x in S yield 属性(on: x)`）；`enough` = `attr` 以题面为语境（「材料够回答 q 吗」），由 `refine` 去向自动调用。[红队 05 A6]
写题五规则由检查器守：一跳字面（题库审核）；一题一对象（E9）；候选集穷尽或带「都不是」（常驻候选集）；量必有锚（E4）；**一题一命题**：复合条件必拆为原子题再用 `∧`/`∨` 合成（§4.4，P1 一跳；两个命题合在一道题里 Jev 读的是一个混合字面，线也没法分别校准），题面含「且 / 或 / 并且 / 或者 / 同时 / 而且」时检查器报 W-compound。

### 6.3 参照库与锚的声明
`anchors 名 = {档: "样例", …}`：每档恰一条，在程序或 `import` 的库里声明；锚指纹进 `Scale` 类型与账本键；换锚 = 新题，旧校准作废并在 viewer 显示。`class`/`cmp` 的「都不是」模板由库提供。

### 6.4 组合子（接受题调用，只补去向；调用时不写 unsure）
三种映射的本质只有门（位）、路由（索引）、阈序（档）；下面是它们落到各槽的具名形式。组合子的参数是**已填好槽的题调用**，组合子不再承担槽。[红队 05 A6]
| 签名 | 语义与固定去向 | 示例 |
|---|---|---|
| `gate(S: Set, x => call) -> Set` | 位→材料门 = `partition` 的 act 流；unsure → `refine` 再 `escalate`（有预算）否则入 W-drop | `gate(段, x => 有观点(on: x))` |
| `take(call[, prior: d]) -> Mat ⊎ unsure` | 索引→材料；有 `prior` 按先验规则保留 d；无则 unsure → `regen`（`over` 来自 `gen`）→ `escalate` → 返回 unsure | `take(最合适(over: 话术库, ctx: 对话))` |
| `route(call: decide over Set[Q]) -> Q ⊎ unsure` | 索引→问题（二阶）；unsure → `escalate` | `(route(先问哪个(over: 题集, ctx: 样本)))(on: x)` |
| `threshold(M: Map[Mat, Level], 档) -> Set` | 档→材料：`≥ 档` 的进；unsure 档入 unsure 流由调用处接 | `threshold(分, 中)` |
| `rank`、`top`、`mark_unsure` | 见 §4.7 | |
`dispatch`、`rescale`、`allocate`、`retitle` 从 v1 删去，列 §12（签名未闭合）。

### 6.5 骨架（用 Jv 写的库程序）
`filter`（partition）、`pick`（select 含置换与先验）、`rank`（偏序）、`divide`（拆块→出口摘要→再判）、`search`（做→观察→判→定→做，带已访集合、不可逆闸门）、`choose_then_verify`（选型：预测 + 事后回填）、`tournament`（非默认，K > 255 或判据本身相对时；unsure 组晋级前二且晋级总数 ≤ 上一轮一半）。
`derive`（二阶推导，[假设 #19·未实现]）与 `preview`（[假设 #24·未测]）**不随 v1 交付**，列 §12。[红队 05 B6]

**`group_by`（归组骨架，v1.1 新增）**
- 签名：`group_by(S: Set, (x, y) => call, k: Int = 8) -> Map[Mat, 组 ⊎ unsure]`。`call` 是一道 `rel` 题（如「x 与 y 说的是同一个 bug 吗」），`k` 是每个对象比较的邻居数。
- 实现：对每个 `x ∈ S` 取 `neighbors(S, x, k)` 作候选，按 10 §3.2 的注意题下沉（一次调用问「这 k 个里哪些与 x 同组」，物理形式按 §5.1 select/subset 规则），得 act 边；宿主并查集合并 act 边成组，组号是标签；**unsure 边与 failed 边不连**（不合并、不拆分），只入账本与 `jv replay`；所有边都 unsure 的对象值位为 `unsure`。
- 成本：`|S|` 次调用一层（不是 `|S|²`）；`k` 由校准库按候选长度定，默认 8。
- 一行示例：`let 组 = group_by(反馈, (x, y) => 同一bug(on: x, ctx: y))` → `Map`，按 `hist(组)` 看各组大小。
- 为什么返回 `Map` 而不是嵌套集合：类型表里没有 `Set[Set]`，而 `Map` 的值位本来就显式带 unsure，归组结果的 unsure 因此不会被静默丢（E3）。

### 6.6 冷启动与校准状态
题的校准状态：`冷`（无验题：保守默认线 hi 0.75 / lo 0.25，所有出口带「未校准」标记，累计 20 条人答自动转入验题）→ `上岗` → `停岗`；`待真值`（预测类，真值到达后算错误率）。

## 8. 校准分题型

- test：hi/lo 两条线，δ 0.05，验题 3 act + 3 ignore，缝 ≥ 0.20；停岗 n ≥ 20 且错误率 > 2ε。
- select：置换一致率 ≥ 97% 才上岗；每选项 3 题 + 「都不是」3 题；边际线（先验规则用）与线₂ 从标注数据按 K 扫描，不设硬下限；unsure 率 > 30% 的 K 禁用。
- measure：每档 3 题；锚指纹进类型与账本键；相邻档差 < 0.15 → unsure；批不变性 0.90 → 状态不放同伴（E9）。
- 校准键 =（题面，对象槽种类，语境槽种类，物理题型，渲染版本）；下沉改变即换线。
- 错误率带区间：n ≥ 20 报 ±10%，n ≥ 73 报 ±5%。线只从标注数据来，禁止手调。

## 11. 为什么（每条修订的起点 → 推理 → 落点）

- **判断有值、值是出口（§0.5、§3.2，删 E1 改 E3）**：起点是红队 05 A1（E1 与 §3.1 互斥，三条探针把判断当值）。推理：`class` 的分类结果必须能被收集，收集的东西只能是出口；读数仍不可见。落点：出口是 `Mat` 子类型，E1 改守读数与守卫位，E3 守 unsure 处理。
- **文法补七类构造（§2）**：起点是红队 05 A2（文法写不出自己的示例）与读者卡点①④⑤⑨。推理：每一类都是探针里已经在用的东西，不补就是文法撒谎。落点：`binder`、赋值、`do` 入 expr、`if host`、`args`、`partition x in S where`、`callee ::= "(" expr ")"`。
